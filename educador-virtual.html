🎓 Educador Virtual Aprende entendiendo, no memorizando

¿Qué quieres aprender hoy?

El tutor sigue tres fases: primero averigua qué sabes (con preguntas), luego te propone un plan con un mapa de conceptos, y después te enseña paso a paso comprobando que cada idea quede firme.

Para usar el tutor necesitas una clave de API de Anthropic. Agrégala en Ajustes. Mientras tanto, puedes usar la pestaña Cuestionarios sin clave.

La conversación se guarda en el Cuaderno.
Cuestionarios (funcionan sin internet ni clave)

Crea tus propias preguntas de opción múltiple con su explicación, o juega el cuestionario de ejemplo. Las opciones se mezclan solas y siempre puedes elegir “No lo sé” en vez de adivinar.

Cuaderno de la sesión

Todo lo que pasa en el tutor (explicaciones, preguntas y tus respuestas) queda aquí, listo para guardar o abrir en Obsidian.

Clave de API de Anthropic

El tutor usa Claude. Consigue una clave en console.anthropic.com. La clave se guarda solo en este navegador y se envía únicamente a api.anthropic.com.
